Mengapa Harus "index.html"? Karena berfungsi sebagai titik masuk utama (default entry point) yang dicari server untuk menampilkan halaman web Anda. Tanpa index.html, GitHub tidak akan tahu file mana yang harus dimuat pertama kali saat URL diakses, sehingga halaman tidak muncul atau tidak terdeploy dengan benar.
